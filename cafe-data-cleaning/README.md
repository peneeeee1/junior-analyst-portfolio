
# Проект: Аналитика продаж кафе — Очистка данных и подготовка витрины

**Источник данных:** выгрузка `dirty_cafe_sales.csv`

## 📋 О проекте
Менеджер предоставил сырые данные о продажах за год. В исходном файле **`dirty_cafe_sales.csv`** присутствуют критические ошибки: некорректные значения цен, пропуски в полях, дублирующиеся транзакции и мусорные записи (`UNKNOWN`, `ERROR`).

Цель проекта — подготовить надежный фундамент для бизнес-аналитики, создав «витрину» данных (*Data Mart*), которая станет основой для еженедельной отчетности.

> ⚠️ **Важное примечание аналитика:**
> Подготовка фундамента для дальнейшего анализа бизнеса, если подойти к задаче
безответственно, то дальнейший сложный анализ или принятие бизнес решений может не только не помочь бизнесу, но и  навредить ему, помимо этого без подготовки фундамента  вообще не будет возможности принять решения, где анализ данных обязателен

## 🛠 Стек технологий
-   **Язык:** Python 3
-   **Обработка данных:** Pandas, re
-   **Управление зависимостями:** pip (файл `requirements.txt`)
